## Publicar en GitHub Pages

1. Crea un repositorio público llamado `alexisv07.github.io`.
2. Sube el contenido de esta carpeta a la rama `main`.
3. En el repositorio: Settings, Pages, Source "Deploy from a branch", rama `main`, carpeta `/ (root)`, Save.
4. Espera uno o dos minutos y abre https://alexisv07.github.io

## Cambiar algo

- Textos: `index.html`
- Colores y tipografía: `css/style.css` (variables al inicio, en `:root`)
- Logo y favicon: `img/logo.svg`. Imagen del encabezado: `img/banner.jpg`. Foto de perfil: `img/Alexis.webp`.
- Logos de proyectos: archivos `.webp` dentro de `img/`; reemplázalos conservando el nombre.
